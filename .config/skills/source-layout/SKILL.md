# Skill: source-layout

## Main placements of source code

The source code for all evroc components can be found under
`~/development/worktrees/monorepo-worktree/main`. There is a AGENTS.md file that can be read to get
some context of the structure of that repository.

The deployment files for all the evroc components can be found under
`~/development/worktrees/cloud-config-worktree/main`. There is a AGENTS.md file that ca be read
to get some context of the structure of that repository.

## Git worktrees

Both of the above folders of code are within git worktrees and all branches of each live in their
own git worktree.
